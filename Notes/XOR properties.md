- **Identity Property (\(A $\oplus$ 0 = A\))**: XORing any value with zero leaves the value completely unchanged.

- **Self-Inverse Property (\(A $\oplus$ A = 0\))**: XORing any value with itself always results in zero.

- **Commutative Property (\(A $\oplus$ B = B $\oplus$ A\))**: The order of the operands does not change the outcome.

- **Associative Property (\((A $\oplus$ B) $\oplus$ C = A $\oplus$ (B $\oplus$ C)\))**: Grouping order does not matter when chaining multiple XOR operations
